#  Task 8 - Simple Sales Dashboard Design (Power BI)

This repository contains the deliverables for **Task 8** of the Data Analyst Internship Program, which involved designing a simple interactive sales dashboard using **Power BI**.

##  Objective
Build a basic Power BI dashboard that shows:
- Monthly Sales Trend
- Sales by Region
- Sales by Category

The goal is to visually summarize performance and allow interactivity via filters.

## Dataset
- File: `task8dm.xlsx` (or `Superstore_Cleaned.csv`)
- Columns Used: `Order Date`, `Region`, `Category`, `Sales`, `Profit`
##  Tools Used
- Power BI Desktop
- Google Colab (for optional data cleaning using Python and Pandas)

##  Dashboard Features
- **Line Chart**: Sales over `Month-Year`
- **Bar Chart**: Sales by `Region`
- **Donut Chart**: Sales by `Category`
- **Slicer**: Filter data by Region

##  Key Insights
1. **[Example Insight]** West region had the highest sales in Q3.
2. **[Example Insight]** Technology category consistently outperformed Furniture and Office Supplies.
3. **[Example Insight]** Sales increased steadily from January to June.

##  Steps Performed
1. Cleaned dataset in Google Colab (converted Order Date to datetime, added `Month-Year` column).
2. Imported the cleaned data into Power BI.
3. Created visuals with proper formatting, color coding, and interactivity.
4. Exported dashboard as PDF/screenshot and wrote 3–4 key insights.
